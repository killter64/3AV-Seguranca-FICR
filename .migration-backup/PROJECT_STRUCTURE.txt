🎯 FLUXOS IMPLEMENTADOS

1️⃣  REGISTRO
   Email → Senha Rigorosa → CAPTCHA → Verificação Email → Login

2️⃣  LOGIN
   Email + Senha → Proteção Brute-Force (3 tentativas) → MFA

3️⃣  AUTENTICAÇÃO MULTIFATOR
   TOTP (6 dígitos) OU Biometria (WebAuthn)

4️⃣  RECUPERAÇÃO DE SENHA
   Email → Código OTP → Nova Senha

5️⃣  DASHBOARD
   Informações Segurança → Logout Seguro

6️⃣  GUARD DE AUTENTICAÇÃO
   Sem token? → Redireciona para /login

─────────────────────────────────────────────────────────────

🔐 PROTEÇÕES OWASP TOP 10

✅ Força Bruta            3 tentativas + 30s cooldown
✅ XSS                    Escape HTML + Zod
✅ SQL Injection          Validação + comentário backend
✅ CSRF                   SameSite=Strict
✅ Bot Signup             CAPTCHA comportamental
✅ Senha em Claro         Argon2id simulado
✅ Sessão Insegura        JWT com flags HttpOnly/Secure
✅ Headers Ausentes       CSP + HSTS + X-Frame-Options
✅ User Enumeration       Always-success forgot-password
