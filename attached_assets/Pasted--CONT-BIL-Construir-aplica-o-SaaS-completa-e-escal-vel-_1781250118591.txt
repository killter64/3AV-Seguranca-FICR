# CONTÁBIL+ — Construir aplicação SaaS completa e escalável

Desenvolva uma aplicação SaaS real chamada "Contábil+".

Stack obrigatória:

* Next.js 15 App Router
* TypeScript
* TailwindCSS
* shadcn/ui
* Supabase (Free Plan)
* Server Actions
* React Hook Form
* Zod
* Recharts
* TanStack Table
* Lucide Icons

A aplicação deve ser responsiva, moderna e otimizada para desktop e mobile.

Inspirar design em:

* Stripe
* Linear
* Notion

Priorizar simplicidade para:

* MEIs
* Pequenas empresas
* Microempresas
* Contadores autônomos
* Escritórios de contabilidade

# REGRAS IMPORTANTES

NÃO criar apenas protótipos.

Criar código real e funcional.

Todas as funcionalidades que dependem somente do Supabase devem funcionar completamente.

Recursos que exigem integrações pagas ou APIs externas devem possuir:

* interface completa;
* banco de dados pronto;
* arquitetura preparada;
* serviços desacoplados;
* mensagens "Em breve";
* dados simulados ou regras internas temporárias.

Toda a estrutura deve ser preparada para futura substituição dos dados simulados pelas integrações reais.
